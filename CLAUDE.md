# «Улица Радости» – фронтенд (Nuxt 4)

Сайт центра умного развития, Новосибирск. Витрина плюс личный кабинет
родителя с покупками (пробное, абонемент, событие). Сейчас в работе:
регистрация, редизайн трёх страниц записи, столбец «Наши записи» в кабинете.

## Порядок чтения

Перед реализацией и любым архитектурным решением:

1. `context/project-overview.md` – продукт, роли, текущая работа
2. `context/architecture.md` – слои, границы, слой данных, auth, **инварианты**
3. `context/ui-context.md` – тема, токены, типографика, паттерны раскладки
4. `context/code-standards.md` – конвенции кода
5. `context/ai-workflow-rules.md` – протокол работы, размер шага, git
6. `context/progress-tracker.md` – фаза, следующие шаги, открытые вопросы, техдолг, решения

Справочники по необходимости: `context/api.md` (эндпоинты),
`context/content.md` (тексты и картинки), `context/tasks/<задача>/` (`task.md` + `report.md`, индекс – `tasks/README.md`),
`context/backend/` – снимки доков бэка, авторитет у `../ypa-center-backend/docs/`,
`context/testing-strategy-2026-09.md` – стратегия тестирования (защищённый файл,
не перезаписывать; правки только по просьбе владельца, с записью в его журнал).

## Коротко о главном

- API **только** через `app/services/*.service.ts`; `useApi()` и `useXService()` –
  только в setup-контексте
- Типы – один баррель `app/types/index.ts`; `api.d.ts` генерируется, руками не правится
- Ошибки – только `parseApiError`; деньги – только `kopecksToRubles` / `formatRub` (копейки) / `formatRubles` (рубли модели)
- Цвета – токены `--ui-*` и семантические классы, hex в компонентах запрещён
- Маппинг DTO → доменная модель внутри сервиса, суффикс `VM` не используется
- Тесты – Vitest: чистые функции в `tests/unit/` (node), всё, что зависит от Nuxt, – в
  `tests/nuxt/*.nuxt.spec.ts`; сеть подменяется фейковым `ApiFetch`, не моками своего кода
- Компоненты по папкам `layout/`, `ui/`, `promo/` и папкам страниц;
  в шаблонах – с префиксом папки (`UiSectionLeading`, `LayoutHeader`)

## Правила сессии

- Протокол обязателен: контекст → план → **выбор режима владельцем** →
  исполнение порциями → ревью → апрув
- Поведение продукта не выдумывается. Нет требования – вопрос в
  `progress-tracker.md`, работа по пункту стоит
- Изменил архитектуру, скоуп или конвенции – **сначала** правь контекстный файл
- Готово = `bun run check` прошёл **и** проверено в браузере
- Коммитить и пушить только по явной просьбе; без упоминаний ИИ и
  `Co-Authored-By` в сообщениях; сообщения краткие, в одинарных кавычках
- При расхождении документа и кода прав код, документ чинится
