# Снимок документации бэкенда

Файлы в этой папке – **копии** из `../../../ypa-center-backend/docs/`, сделанные
для удобства чтения из фронтового репозитория. Это не источник правды.

- **Снимок обновлён:** 2026-09-22, с ветки `def` (`Frewazik/ypa-center-backend`,
  коммит `79068b5`) – старый снимок был с `feat/frontend-integration`
- **Авторитет:** `ypa-center-backend/docs/`. При расхождении прав бэк, а ещё выше – код бэка.
- **Актуальность контрактов:** проверяется по живой OpenAPI-схеме
  `http://localhost:8000/api/schema/` (`bun run schema:update` кладёт типы в `app/types/api.d.ts`).
  Контейнеры бэка на момент обновления снимка не подтверждены пересобранными под `def` –
  перед `schema:update` убедиться, что `docker compose up -d --build` выполнен.

Править эти копии **можно только вычёркивая лишнее** (например, разделы, не
относящиеся к фронту). Новые факты о бэке дописывать здесь нельзя – они пойдут
в репозиторий бэка и вернутся сюда следующим снимком.

## Что изменилось на `def` относительно прежнего снимка (2026-09-21 → 2026-09-22)

- **Пробные занятия реализованы** (`POST /checkout/trial`, `GET /me/trials/`) –
  раньше в `api-core-contracts.md` были помечены как отложенные
- **Оплата ивентов остаётся не реализована осознанно** – гостевая регистрация
  со статусом `PENDING_PAYMENT`, оплата на месте, бронь освобождается через
  30 минут. Друг переделывает это в онлайн-оплату – контракт `POST /checkout/event`
  появится отдельно, в этом снимке его ещё нет
- **`X-Idempotency-Key` (UUID v4) обязателен** на обоих чекаутах – раньше это
  не было явно перенесено во фронтовые доки
- **Теневая регистрация явно удалена** как архитектурное решение
  (`auth-flow.md` §1.4) – если кто-то предложит тихо создавать `Parent` при
  покупке без OTP, это откат уже принятого и обоснованного решения, не новая идея

## Известные расхождения дока ↔ код

Проверено 2026-09-21/22, дополнять по мере находок.

- `DELETE /me/children/{id}/` на момент прошлой проверки не был реализован –
  входит в текущий фронт-бэк план, проверить по `backend-checklist.md`
  (в корне `ypa-center.ru/`, вне git) после того, как друг сдаст работу.
- `GET /public/gallery/` отдаёт голый массив без query-параметров и конверт
  `{count, next, previous, results}` при `?limit`. Обе формы поддержаны в
  `app/services/gallery.service.ts`.
- Контракт «профиль пуст → показать анкету» после `verify` не имеет явного
  описания в `auth-flow.md` (что именно возвращает бэк – пустые поля или
  флаг). Уточнить у автора бэка, зафиксировано в `backend-checklist.md`.
