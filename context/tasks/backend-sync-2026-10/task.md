## Как работаем: TDD

Каждая подзадача (кроме 00) идёт циклом **red → green → refactor**:

1. **Red.** Сначала пишутся тесты из раздела «Тесты» подзадачи. Запуск
   `bun run test` – новые тесты **падают по правильной причине** (нет функции,
   неверное значение), а не из-за опечатки или импорта. Вывод падения – в отчёт.
2. **Green.** Минимальный код, чтобы тесты прошли. Ничего сверх тестов.
3. **Refactor.** Чистка при зелёных тестах, затем `bun run check` целиком.
4. **Браузер** – для подзадач с UI (тесты его не заменяют, `CLAUDE.md`).

Правила тестов – `testing-strategy-2026-09.md` §13: поведение, а не реализация;
шов – фейковый `ApiFetch` / `$fetch`, свой код не мокается; время и пояс
закреплены (`Asia/Novosibirsk`); деньги – точные строки в копейках; ошибки – по
`code`; фикстуры DTO – из типов `app/types`; без `any`, `as`, `!`. Таблицы
крайних случаев – `it.each`. Раскладка: `tests/unit/**/*.spec.ts` (чистые
функции), `tests/nuxt/**/*.nuxt.spec.ts` (сервисы, композаблы, компоненты).

## Вне задачи

- Остаток мест события (`MOCK(event-seats)`, вопрос 24) – бэк его не отдаёт.
- Возраст и второе описание события (вопрос 25).
- E2E (Playwright) – вне объёма по решению владельца; живую оплату на тестовом
  магазине ЮKassa проверяем руками в 05.

## Критерии приёмки всей задачи

- Все подзадачи закрыты, `bun run check` (с тестами) зелёный.
- Каждый новый тест хотя бы раз видели красным (вывод в `report.md`).
- Тестовый магазин ЮKassa: платное событие гостем → оплата → успех на
  `/checkout/result?…&kind=event` без входа; отмена → экран отмены; бесплатное
  событие → «Заявка принята».
- Абонемент на N слотов уходит с тарифом ровно на N или безлимитом.
- Бесплатное пробное оформляется без ЮKassa.
- `rg "на месте|позвонит" app` – пусто.
