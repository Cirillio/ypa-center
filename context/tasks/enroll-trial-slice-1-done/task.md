# Задача: страница «Пробное занятие», срез 1 – каркас + выбор кружка и времени

Шаг 2 плана (редизайн покупок) разморожен владельцем для этой задачи.
Перед началом прочитай `CLAUDE.md` проекта и всё из «Порядок чтения» – протокол
(план → апрув → порциями, без коммита) уже там.

## Цель

Новая версия `/enroll/trial`: каркас страницы, вкладки типа покупки и два
виджета выбора – «Кружок» и «Дата и время». Готово = раскладка, состав блоков,
тексты и поведение совпадают с макетом в состояниях из «Приёмки»; стилизация –
средствами проекта.

## Эталон

`mockups/checkout-trial.html` (собранный файл; источники – `mockups/_src/`).
**Разметка виджетов и состояний частично генерируется в `<script>`** (`renderClubs`,
`renderSlots`), читай HTML вместе со скриптом. Открывать макет нужно через
браузерный инструмент; CDN нужен интернет, картинки в макете не загрузятся
(битый относительный путь) – это нормально, ориентир только вёрстка.

**Макет – иллюстрация, а не дизайн-система.** Он даёт раскладку, состав блоков,
тексты и поведение. Классы, цвета, токены, `text-ink/*`, `bg-ink/*`, `p-3.75`,
`.widget`, `ic()` не переносить. Стилизуй так, как сделаны остальные страницы:
компоненты Nuxt UI (`UButton`, `UBadge`, `UIcon`, `UContainer`, `USeparator`…),
`app.config.ts`, `tokens.css`, семантические классы (`text-default`, `text-muted`,
`bg-default`, `border-default`). **Новых цветов и токенов не добавлять.**
Полупрозрачный текст `text-default/50|60|70` использовать нельзя (контраст,
см. техдолг в трекере) – только `text-muted`. Образец оформления виджета и
заголовка блока – `components/me/*/Widget.vue`, `Card.vue`. Уже есть
`ui/RadioCard.vue` – проверь, годится ли для карточек выбора.

Не переносить из макета: devbar, CDN, выдуманные данные (`CLUBS`, `GROUPS`,
`LIMIT_USED`), глобальные `Kids`/`Pay`, шапку сайта (`header.html`), модалку оплаты.

## Объём

Входит:

1. Каркас страницы: компактный заголовок («Запись» + h1 с иконкой) и навигация
   по трём типам покупки (Пробное / Абонемент / Событие; на абонемент и событие
   ведут существующие маршруты `EnrollRoutesEnum`).
2. Раскладка `lg:grid-cols-7`: слева (5) виджеты, справа (2) `<aside>` под
   «Итого» – **пустой контейнер с sticky-позиционированием**, содержимое – в срезе 2.
3. Виджет «Кружок» (radiogroup карточек).
4. Виджет «Дата и время» (radiogroup карточек слотов).

Не входит (не трогать, не заглушать логикой): сводка «Итого», выбор ребёнка, кнопка
«Продолжить», нижняя панель `#mbar`, модалка оплаты и любая оплата, `/me`,
старые компоненты страницы (`components/trial/*`, `shared/EnrollmentSummary`,
`shared/RegistrationForm`, `promo/*` на этой странице) – они удаляются отдельной
задачей. Страницы абонемента и события не менять.

## Дерево компонентов (обязательное; отклонения – только с обоснованием в отчёте)

Новые компоненты кладём в новую папку, чтобы не пересечься по автоимпорту
со старым `components/trial/` (префикс `Trial…` занят):

```
pages/enroll/trial-new.vue          – временный маршрут /enroll/trial-new
components/enroll/
  Header.vue                        – EnrollHeader: иконка, «Запись», h1, слот под вкладки
  TypeTabs.vue                      – EnrollTypeTabs: навигация Пробное/Абонемент/Событие
  trial/
    ClubWidget.vue                  – EnrollTrialClubWidget: заголовок блока + сетка
    ClubCard.vue                    – EnrollTrialClubCard: карточка кружка (radio)
    SlotWidget.vue                  – EnrollTrialSlotWidget: заголовок + сетка + пустое состояние
    SlotCard.vue                    – EnrollTrialSlotCard: карточка слота (radio)
composables/useTrialCheckout.ts     – состояние выбора (clubId, slotId), производные
```

Почему временный `trial-new.vue`: пока нет сводки и оплаты, подмена `trial.vue`
сломала бы рабочую страницу. Замена файла – последняя задача серии. Если видишь
причину сделать иначе – напиши в плане.

`EnrollTypeTabs` и `EnrollHeader` общие для трёх страниц: не привязывай их к пробному.
Для вкладок выбери подходящий компонент Nuxt UI (в проекте `UTabs` встречается
один раз; это навигация по маршрутам, а не переключение контента – реши сам и
обоснуй в плане).

## Данные

- Кружки и слоты: пока `MOCK_CLUBS_WITH_SLOTS` из `app/constants/mock.ts` (тип
  `ClubWithSlots`, слот `WeeklySlot` с `available`/`maxCapacity`, дата слота –
  ближайшая через `useFormatDate().getClosestDate`, как в `useTrialEnrollment`).
  Нового мока в `constants/mock.ts` не добавлять. Если полей для макета не хватает
  (возрастной бейдж «5–12 лет», описание кружка) – **не выдумывай**: не показывай
  блок и запиши вопрос в трекер.
- API для пробного нет: `checkout/trial` и слоты пробного в сервисах отсутствуют.
  Контракты – `context/backend/checkout-flow.md`, `api-core-contracts.md`.
- Старый `useTrialEnrollment` не менять и не использовать (привязан к старой форме).
  Логику выбора/сортировки слотов можно взять как образец.
- Сброс слота при смене кружка – как в макете и как в старом композабле.
- Синхронизация выбора с query (`clubId`, `slotId`) – как в старом композабле
  (нужно для перехода с других страниц); `pid` не трогать (оплата).

## Обязательное поведение (из макета)

Виджет «Кружок»: карточка = фото, название, описание, бейдж возраста; выбранная
подсвечена и получает отмеченную иконку; `role="radio"`/`radiogroup`, клавиатура.
Сетка 1 колонка на 375, 2 – `sm`, 3 – `xl`.

Виджет «Дата и время»:

- кружок не выбран → пустое состояние «Сначала выберите кружок»;
- кружок выбран → сетка слотов (`md:grid-cols-2`): дата, время, группа, «Мест: N/M»;
- цвет счётчика мест: 0 – приглушённый, ≤3 – предупреждающий, иначе –
  успешный; подбери семантические цвета проекта, не hex;
- слот без мест: disabled, «Мест нет», нельзя выбрать;
- выбранный слот подсвечен; смена кружка сбрасывает выбор слота.

## Приёмка

- `bun run check` без ошибок.
- Браузер (встроенный), ширины 375 и 1440, маршрут `/enroll/trial-new`, рядом
  макет; состояния сверять по блоку «Страница» devbar («Пусто» / «Заполнено»)
  и кликами: кружок не выбран; кружок выбран; слот выбран; слот без мест;
  смена кружка сбрасывает слот. Блок «Модалка оплаты» devbar – **вне среза**.
- Нет горизонтального скролла на 375; вкладки на 375 скроллятся, не ломая раскладку.
- В новых файлах нет hex-цветов, `text-default/xx`, `any`, `as Type`, function-props,
  индексов в `key`; над каждой новой функцией/компонентом одна строка-комментарий WHY.
- В отчёте честно раздели «проверено» и «не проверено», перечисли отклонения
  от дерева и записанные вопросы.
