# Задача: Тост при переходе по ссылке на событие без свободных мест

**Статус:** Выполнена

---

## 1. Контекст и проблема

Пользователь может прийти на страницу оформления события по прямой ссылке с query-параметром, например:
`/enroll/event?eventId=12`

В `useEventCheckout.ts` действует правило: если событие заполнено (`availableSeats <= 0`), `selectedEventId` сбрасывается в `undefined`, а в `onMounted` ссылка очищается через `router.replace` до `/enroll/event`.

**Проблема UX:**
Пользователь не понимает, почему событие не выбралось: экран выглядит так, будто он просто зашел на пустую страницу записи, а карточка события с бейджем «Мест нет» может находиться далеко внизу списка афиши.

---

## 2. Требования к решению

1. При монтировании страницы `/enroll/event` (`useEventCheckout`):
    - Если в URL был передан `eventId` (`rawQueryEventId !== undefined`);
    - Список событий `events` успешно загружен;
    - В списке найдено событие с этим ID (`targetEvent = events.find(e => e.id === parsedInitialId)`);
    - И у этого события нет свободных мест (`targetEvent.availableSeats <= 0`):
        - Показать информационный тост через `useToast()`.
2. **Параметры тоста:**
    - `title`: «Все места заняты»
    - `description`: «На событие «{Название}» запись закрыта. Выберите другое мероприятие из афиши.»
    - `color`: `"neutral"` (или `"warning"`)
    - `icon`: `"ph:users-three-bold"`
3. URL по-прежнему мягко очищается (`syncQuery(undefined)`), предотвращая невалидное состояние в query.
4. Если передан несуществующий ID (события нет в списке) — тост не показывать (или показывать «Событие не найдено», если требуется), query просто очищается как раньше.

---

## 3. Критерии приёмки

- [ ] При переходе на `/enroll/event?eventId={id-заполненного-события}` появляется тост с названием этого события.
- [ ] Параметр `eventId` удаляется из query-строки без создания лишней записи в истории браузера.
- [ ] При переходе на событие со свободными местами тост НЕ появляется, событие выбирается штатно.
- [ ] `bun run check` (типы, линт, билд) проходит чисто.
