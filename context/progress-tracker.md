## Заметки для следующей сессии

- Начинать так: «Прочитай `CLAUDE.md` и `context/progress-tracker.md`, затем
  `<конкретная задача>`». Не «изучи проект».
- Одна задача – одна сессия. Не смешивать флоу регистрации, редизайн страниц
  покупки и правки кабинета в одной сессии – это разные куски плана.
- Перед началом работы: `cd ypa-center-backend && git status` – убедиться, что
  всё ещё на `def`; `docker compose up -d --build`, если контейнеры не
  пересобраны под новый код.
- Память ИИ – не источник правды о проекте. Источник – `context/` и код.
- При `ENVIRONMENT=local` письма уходят в консоль, тело в логе воркера
  закодировано base64. Код OTP берётся из БД:

    ```bash
    cd ypa-center-backend && .venv/bin/python manage.py shell -c "from apps.users.models import MagicTokens; t=MagicTokens.objects.filter(email='kirill-io3@yandex.ru', is_used=False).order_by('-created_at').first(); print(t.code, t.expires_at) if t else print('нет активного кода')"
    ```

- Тестовый родитель – `kirill-io3@yandex.ru` с одной дочерью. Демо-данные:
  `manage.py seed_demo` (только `DEBUG=True`). Cooldown OTP 60 с, TTL кода 5 мин.
- `docker compose ps` из другого cwd иногда возвращает пусто – надёжнее
  `docker ps --filter name=ypa-center-backend`.
